# SLink agent entry

At session start, resume, compaction and before concluding SLink work, apply [the orchestration contract](docs/agents/orchestration.md) and refresh the active guide checkpoint.

For any Gen 1 R/B/Y source, test, release, or documentation task, read [the universal Gen 1 entry](docs/gen1_reference/README.md) before acting. It routes every agent type to the one current guide, worktree register, claim gate, and handoff contract. Other SLink games and UI lanes keep their own owners.

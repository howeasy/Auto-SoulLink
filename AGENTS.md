Claim one named small work package and its exclusive files; code only inside that scope. Do not use a new worktree, run an emulator/Java performance job, modify shared runtime paths, import a save, or alter release hashes without the guide's owner and gate. Send the integrator a compact UTC/HEAD/files/receipt/pass-fail/skips/unknowns/next-owner handoff; the integrator updates the guide at every transition. Source/model/fixture evidence is never a paired playthrough or release proof.

Other SLink game/UI projects have separate owners and are not authorized by this Gen 1 guide.

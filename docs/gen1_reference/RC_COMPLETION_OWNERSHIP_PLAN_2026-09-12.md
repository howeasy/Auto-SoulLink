1. **A1 — current-source profile, one bounded optimization.** The A owner has measured `Gen1Runtime.state()` ~51 ms per changed event; inventory and initial-save audits are the largest pure costs. 3. **B2 — classifier before execution.** Claude supplies a table of each lease/WRAM/CartRAM/file/host state and permitted action before enabling forward recovery. `native.json` missing or rolled back, an `armed` lease after process replacement, mixed ROM state, or equal B/A bytes are **unknown**, not proof of never-applied. Run the minimum controlled mid-routine probe only in an exclusive emulator lane; if the normal crash path cannot be distinguished safely, stop for an owner decision. 4. **B3 — production route and fault matrix.** Only after A merges and the shared-file handoff, provide a hash-pinned `PreparedCartridges`-compatible artifact object for the canonical companion-patched clean pair, accepted by `create_runtime`, `Gen1Runtime` and the checked launcher **without** relaxing the existing refusal of an unprepared clean/native run (`gen1_run_config.py:109`, `gen1_runtime.py:117`). Enable free_service+native_trade idle continuity only when the coordinator phase is in `TERMINAL={cancelled,declined,expired,link_committed}` and journal/native obligations are empty; active/uncertain trade remains held. Root reviews the current runtime hook integration and reruns targeted native/paired integration and the controlled fault matrix, including an open release receipt after `link_committed`. A component or held-fixture pass does not qualify the production route.
5. **Integrated acceptance and pause.** Merge A and B only after independent review with no unresolved high finding. Testing discipline: one owner per file/subsystem, targeted suites per commit, one isolated live run per measured hypothesis, and no full 7,000+ node suite or release-hash repin until the A+B source freeze.

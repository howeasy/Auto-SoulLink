## Tool quirks that cost time (avoid re-learning)

- The Bash tool breaks on an odd number of apostrophes anywhere in the command, including
  heredoc bodies and Python source. Use only double quotes in heredoc Python, or write files
  with the Write tool into the scratchpad and `cp` them.
- Write/Edit refuse paths in other worktrees; new worktree files go via scratchpad + `cp`.
- `git diff --no-index --src-prefix= --dst-prefix= a b` from a staging dir yields `a/<path>`
  and `b/<path>` headers that `git apply` accepts from the worktree root.
- The auto-mode classifier can be temporarily unavailable; retry Bash after a moment.
- `robocopy` fails from Git Bash with spaced paths; use `tar --force-local` pipes; junctions
  via PowerShell `New-Item -ItemType Junction`.
- Browser patcher tests (`tests/integration/test_gen1_browser_patcher.py`, four cases) need the `playwright` npm
  package and a Chromium: install with `npm install --prefix .cache/node playwright` (gitignored) and run pytest with
  `NODE_PATH=<worktree>/.cache/node/node_modules` and `SLINK_CHROMIUM=%LOCALAPPDATA%/ms-playwright/chromium-1223/chrome-win64/chrome.exe`
  (the cached build; Playwright 1.63 wants 1243 but drives 1223 fine). No download needed; 4 passed in 13 s on 2026-09-11.

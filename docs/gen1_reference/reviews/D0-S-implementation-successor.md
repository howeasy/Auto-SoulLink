The existing SelectedRun final audit checks that plan and requires the driver's `input-stopped` marker. Driver progress/failure JSON stays in the owned player emulator directory and is included in the run outcome; failure causes HOLD. The default product CLI path and its evidence checks remain distinct.

The Lua wrapper reuses the selected-fresh gate's `menu_inputs` pulse/menu selection and its native owned-frame conditions. It applies only `joypad.set` on the launcher's own clean boot-frame calls, clears buttons under held yield and when the observation loop begins, then restores its own hooks and delegates that frame exactly once. Later ordinary frames no longer poll status or inject idle; conditional restoration preserves any later owner's replacement hooks. It does not advance pre-launch intro frames or perform RAM/register/SaveRAM/savestate writes. A frame/time no-progress bound applies during New Game input only; the outer SelectedRun timeout remains 1800 seconds. A held-frame advance or unexpected phase fails before an extra frame. The original gate's performance RAM probes, movement, FPS phases and gate result files are not used.

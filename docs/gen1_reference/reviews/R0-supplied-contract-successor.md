## 0. What the classifier is

`classify(evidence) -> Verdict` is a pure function: no I/O, journal lookup, producer construction, persistence, rebind, window grant, replay or actuator. It **derives** only from bytes it is handed (overlay decoding, image equalities, the overworld-checkpoint arithmetic when its full evidence is supplied, lease/window consistency) and **trusts** the caller's typed attestations for everything that requires a witness it cannot obtain (history availability, lease presence/floor, host lineage, held-frame provenance, CPU location inside the routine). It never upgrades a supplied attestation and never decides an action. **[R2]** `Verdict = {row: 1..11, class: str, constraints: tuple[str, ...], refusals: tuple[str, ...], derived: dict}`: rows 1–9 have empty `refusals`; policy-held decidable rows carry `constraints` naming the hold (`"hold:rule0"` rows 2/4, `"hold:p2b_refused"` rows 6–8, `"hold:owner_policy"` row 8); rows 10/11 carry non-empty `refusals` naming the field or contradiction. No field is an action, grant or release. Classes are rev4's strings: `never_issued, armed_without_authority, credits_unused, armed_pending, in_progress, done_unreleased, process_replaced, process_replaced_saved, saved_unwitnessed, unknown, rolled_back`.

## 2. Precedence (evaluated in this order; the first hit returns)

P0 **malformed**: any group missing a required key, wrong domain/casing, or `evidence_digest` mismatch → refuse `malformed:<group.field>` (row 10). P1 **scope**: `trade_phase ≠ post_commit` → refuse `outside_scope` (row 10; pre-COMMIT is abort territory, not R0). P2 **[R2] witnessed rollback** (rev4 row 11 only): `host.rollback.status == detected` with basis `frame_regression` (same process, framecount below the durable window frame) or `file_older` (S older than the prepared image) → row 11 `rolled_back`. P3 **[R2][R3] incoherence** (row 10, named): overlay published with a token matching no lease record; published `phase ∉ {5, 7}` (`unsupported_overlay_phase`); published DONE with `result byte8 == 2`; `host.status == replaced` with `lease.record.phase == armed` and no supplied re-enrollment witness (`unknown:armed_lease_without_reenrollment`, rev4 `:80`); `S_is_B == false` with `execution.observed_prefix < 4` on a same process (only hook 4 writes SRAM, §3 row 5); `execution.observed_prefix < window.prefix`; lease/window/scope command, intent or token mismatch; a `complete` lease receipt with `window.status == verified_absent`; `S_is_A && !equal_byte` while `host.status == same` and `execution.observed_prefix < 4` and no `done_halt` attestation. Image shapes are otherwise judged **per row** below, never globally. P4 **unknowns** (row 10, named): `host.status == unknown`; `lease.presence ∈ {missing, unknown}`; **[R2]** `lease_below_floor` (rev4 `:80`); `lease.floor.status == unknown` when a lease record exists; `window.status == unavailable`; any group a candidate row requires reported `unavailable`. P5 **[R3] replaced process** (`host.status == replaced`, requires `S.basis == boot_witness` and `R.basis == boot_read`, else `unknown:boot_witness`), evaluated in this order so every input lands: (a) `equal_byte` → row 6 (rule 3; `F` irrelevant, `derived.equal_byte = true`); (b) `window.prefix == 4` and `S_is_A` and `R_is_A` and `F.basis == boot_file_witness` and `F_matches_S` → row 7; (c) `window.prefix == 4` and `S_is_A` and `R_is_A` and `F` unavailable or not a boot-file witness → row 10 `unknown:F`; (d) `window ∈ {verified_absent, prefix < 4}` and `S_is_B` and `R_is_B` → row 6; (e) `window ∈ {verified_absent, prefix < 4}` and `S_is_A` and `R_is_A` and not `S_is_B` → row 8; (f) anything else → row 10 `unmatched_shape`. Each decidable row carries `constraints ("hold:p2b_refused",)`. P6 **same process**: rows 1–5 in numeric order by the required evidence below. P7 residual → row 10 `unmatched_shape`.

## 5. Boundary of proof

Derived by the classifier (checkable in unit tests from bytes alone): overlay decoding; the overworld checkpoint **only** when PC, the four ROM opcode anchors, the live flag bytes and the two stack words are all supplied and all pass `gen1_write_safety`'s checks; image/party equalities on exact operands (`B`/`A_pred` already projected by `gen1_full_save.image`, supplied as such); `S_partial_toward_A` from the pinned write order; `F_matches_S` as a consistency relation between two supplied values; lease/window/execution consistency and `lease_below_floor` arithmetic. Supplied and trusted as attestations (R0b or later cards must produce and verify them; none exists today and none is proposed here): `window.status == verified_absent`, `lease.presence`, `lease.floor`, `host.status/lineage/rollback` witnesses, `held_read_frame`, `S.basis == boot_witness`, `R.basis == boot_read`, `F.basis == boot_file_witness`, a re-enrollment witness for an armed lease on a replaced process, `execution.observed_prefix` (volatile, same process only) and `execution.cpu_location ∈ {inside_routine, done_halt}`, file presence/readback. The output is diagnostic; it grants no window, replay, rebind or release, and P2b's refusal is not a field it can flip.

## 0. What the classifier is

`classify(evidence) -> Verdict` is a pure function: no I/O, journal lookup, producer construction, persistence, rebind, window grant, replay or actuator. It **derives** only from bytes it is handed (overlay decoding, image equalities, the overworld-checkpoint arithmetic when its full evidence is supplied, lease/window consistency) and **trusts** the caller's typed attestations for everything that requires a witness it cannot obtain (history availability, lease presence/floor, host lineage, held-frame provenance, CPU location inside the routine). It never upgrades a supplied attestation and never decides an action. **[R2]** `Verdict = {row: 1..11, class: str, constraints: tuple[str, ...], refusals: tuple[str, ...], derived: dict}`: rows 1–9 have empty `refusals`; policy-held decidable rows carry `constraints` naming the hold (`"hold:rule0"` rows 2/4, `"hold:p2b_refused"` rows 6–8, `"hold:owner_policy"` row 8); rows 10/11 carry non-empty `refusals` naming the field or contradiction. No field is an action, grant or release. Classes are rev4's strings: `never_issued, armed_without_authority, credits_unused, armed_pending, in_progress, done_unreleased, process_replaced, process_replaced_saved, saved_unwitnessed, unknown, rolled_back`.

## 2. Precedence (evaluated in this order; the first hit returns)

P0 **malformed**: any group missing a required key, wrong domain/casing, or `evidence_digest` mismatch → refuse `malformed:<group.field>` (row 10). P1 **scope**: `trade_phase ≠ post_commit` → refuse `outside_scope` (row 10; pre-COMMIT is abort territory, not R0). P2 **[R2] witnessed rollback** (rev4 row 11 only): `host.rollback.status == detected` with basis `frame_regression` (same process, framecount below the durable window frame) or `file_older` (S older than the prepared image) → row 11 `rolled_back`. P3 **[R2] incoherence** (row 10, named): overlay published with a token matching no lease record; `result byte8 == 2`; `execution.observed_prefix < window.prefix`; lease/window/scope command, intent or token mismatch; a `complete` lease receipt with `window.status == verified_absent`; `S_is_A && !equal_byte` while `host.status == same` and `execution.observed_prefix < 4` and no `done_halt` attestation. Image shapes are otherwise judged **per row** below, never globally. P4 **unknowns** (row 10, named): `host.status == unknown`; `lease.presence ∈ {missing, unknown}`; **[R2]** `lease_below_floor` (rev4 `:80`); `lease.floor.status == unknown` when a lease record exists; `window.status == unavailable`; any group a candidate row requires reported `unavailable`. P5 **replaced process** (`host.status == replaced`): rows 6/7/8 by `S` and `window.prefix`, each with `constraints ("hold:p2b_refused",)`; equal-byte never changes the class. P6 **same process**: rows 1–5 in numeric order by the required evidence below. P7 residual → row 10 `unmatched_shape`.

## 5. Boundary of proof

Derived by the classifier (checkable in unit tests from bytes alone): overlay decoding; the overworld checkpoint **only** when PC, the four ROM opcode anchors, the live flag bytes and the two stack words are all supplied and all pass `gen1_write_safety`'s checks; image/party equalities on exact operands; `F_matches_S` as a consistency relation between two supplied values; lease/window/execution consistency and `lease_below_floor` arithmetic. Supplied and trusted as attestations (R0b or later cards must produce and verify them; none exists today and none is proposed here): `window.status == verified_absent`, `lease.presence`, `lease.floor`, `host.status/lineage/rollback` witnesses, `held_read_frame`, `S.basis == boot_witness`, `execution.observed_prefix` (volatile, same process only) and `execution.cpu_location ∈ {inside_routine, done_halt}`, file presence/readback. The output is diagnostic; it grants no window, replay, rebind or release, and P2b's refusal is not a field it can flip.

## Unknown / unverified

Whether overlay byte 5 value 8 (RELEASE, `trade_service.asm:142-144`) is observable in a held read before the cartridge restores the overlay; treated as `unmatched_shape` here. The exact `location_basis` vocabulary for `inside_routine` (bounded-stepper PC range inside `SlinkTradeService` versus a companion-manifest bank/range check) is R0b's to define; this contract only requires that it be supplied, never derived from the overworld profile.

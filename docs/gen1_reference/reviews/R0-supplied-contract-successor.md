## 0. What the classifier is

`classify(evidence) -> Verdict` is a pure function: no I/O, journal lookup, producer construction, persistence, rebind, window grant, replay or actuator. It **derives** only from bytes it is handed (overlay decoding, image equalities, stack-invariant arithmetic, lease/window consistency) and **trusts** the caller's typed attestations for everything that requires a witness it cannot obtain (history availability, lease presence/floor, host lineage, held-frame provenance). It never upgrades a supplied attestation and never decides an action. `Verdict = {row: 1..11, class: str, refusals: tuple[str, ...], derived: dict}`; a non-empty `refusals` implies `class == "unknown"` (row 10) or `"rolled_back"` (row 11), never a decidable row. Classes are rev4's strings: `never_issued, armed_without_authority, credits_unused, armed_pending, in_progress, done_unreleased, process_replaced, process_replaced_saved, saved_unwitnessed, unknown, rolled_back`.

## 2. Precedence (evaluated in this order; the first hit returns)

P0 **malformed**: any group missing a required key, wrong domain, or `evidence_digest` mismatch → refuse `malformed:<group.field>` (row 10). P1 **scope**: `trade_phase ≠ post_commit` → refuse `outside_scope` (row 10; pre-COMMIT is abort territory, not R0). P2 **rollback**: `host.rollback.status == detected` or derived `rolled_back_lease` → row 11 `rolled_back`. P3 **incoherence**: overlay published with a token matching no lease record, `result byte8 == 2`, lease `receipt.prefix > window.prefix`, lease/window intent or command mismatch, `R`/`S` equal to neither `B` nor `A_pred` → row 10 with the named contradiction. P4 **unknowns**: `host.status == unknown`, `lease.presence ∈ {missing, unknown}`, `lease.floor.status == unknown` when a lease exists, `window.status == unavailable`, or any group a candidate row requires reported `unavailable` → row 10 `unknown:<field>`. P5 **replaced process** (`host.status == replaced`): rows 6/7/8 by `S` and `window.prefix`; all three classes are HOLD while P2b is refused; equal-byte never changes the class. P6 **same process**: rows 1–5 in numeric order by the required evidence below. P7 residual → row 10 `unmatched_shape`.

## 3. Per-row required / irrelevant / missing treatment (same process unless stated)

| Row | Required (all must be verified/read) | Irrelevant | Missing or `unavailable` | Result |
| --- | --- | --- | --- | --- |
| 1 `never_issued` | `window.status == verified_absent`; `lease.presence == present` with `record.phase ∈ {idle, released}` and `receipt.status == absent`; `overlay` read and `published == false` (or `not_applicable` only if `host.status == replaced`, then row 6); `S == B` and `R == party(B)` | `cpu`, `F`, `A_pred` equality | any required → row 10 (`unknown:window` for `unavailable`) | decidable |
| 2 `armed_without_authority` | `window.status == verified_absent`; overlay `published && phase == 5 && token == scope.token_hex`; `S == B` | `cpu`, lease receipt | overlay `unavailable` → row 10 | decidable, HOLD class |
| 3 `credits_unused` | `window.verified_present` with `prefix == 0`; overlay read: `published == false` or `consumed` (b6 == b7); `lease.record.receipt.status == absent`; `cpu.checkpoint == overworld_wait` (derived from raw words); `S == B`, `R == party(B)`. **Equal-byte (`B == A_pred`) is irrelevant** (rule 3): it neither adds nor removes evidence. | `F`, peer, equal-byte flag | `cpu` or `overlay` unavailable → row 10 `unknown:cpu`/`unknown:overlay`; never inferred from bytes | decidable |
| 4 `armed_pending` | `window.prefix == 0`; overlay `published && phase == 5 && pending (b6 ≠ b7) && token == scope.token_hex`; `lease.record.phase == armed` with the same token; `cpu.checkpoint == overworld_wait`; `S == B` | equal-byte | `cpu` unavailable → row 10; `cpu.checkpoint ∈ {inside_routine, done_halt}` → row 5; `other` → row 10 | decidable, HOLD class (rule 0) |
| 5 `in_progress` / `done_unreleased` | `window.prefix ≥ 1` or overlay `phase == 7`; `cpu.checkpoint ∈ {inside_routine, done_halt}`; `host.held_read_frame ≥ window.entry.frame`; lease `record.phase ∈ {armed, complete}` consistent with `receipt.prefix ≤ window.prefix`; `S ∈ {B, A_pred}`, `R` partial or `A` | equal-byte; `F` | any → row 10 | decidable, forward class (action not authorized here) |
| 6 `process_replaced` | `host.status == replaced`; `window.status ≠ unavailable` with `prefix < 4` (or `verified_absent`); `S == B` at a supplied witnessed boot; `R == party(B)` | overlay, cpu (WRAM re-derived) | window `unavailable` → row 10; boot witness `unavailable` → row 10 | HOLD (P2b refused) |
| 7 `process_replaced_saved` | `host.status == replaced`; `window.verified_present` with `prefix == 4`; `S == A_pred`; `F` supplied with `F.sha256 == sha256(S)` | overlay, cpu | `F` unavailable → row 10 | HOLD |
| 8 `saved_unwitnessed` | `host.status == replaced`; `window` verified with `prefix < 4` or `verified_absent`; `S == A_pred`, `S ≠ B` | overlay, cpu | window unavailable → row 10 | HOLD, owner policy |
| 9 peer | none (modifier) | everything | — | never changes the local row/class; `derived.peer_phase` recorded |
| 10 `unknown` | any P0/P3/P4/P7 hit | — | — | refusal with named field |
| 11 `rolled_back` | P2 hit | — | — | permanent HOLD |

Equal-byte trades in rows 6–8: `S == B == A_pred` makes rows 7/8's `S == A_pred` tests vacuous; the classifier reports row 6 with `derived.equal_byte = true` and never `unknown` merely for equality (rule 3). It records no action.

## 4. Examples (inputs abbreviated to the deciding groups)

- **Row 1 positive:** `host.same`, `window={status: verified_absent}`, `lease={presence: present, observed_revision: 3, floor: {verified, 1}, record: {phase: idle, receipt: absent}}`, overlay bytes `00…` (not published), `S == B`, `R == party(B)` → `{row: 1, class: never_issued, refusals: ()}`.
- **Row 1 refusal (no-window vs unavailable):** identical, but `window={status: unavailable, reason: "current admission mismatch"}` (what `durable_progress` returning `None` means today) → `{row: 10, class: unknown, refusals: ("unknown:window",)}`. A wrapper that maps `None` to `verified_absent` fails this case.
- **Row 3 equal-byte positive:** `B == A_pred`, `window.verified_present prefix 0`, overlay `00 00 …` (magic absent → `published == false`, the before-window never wrote it) or `53 4C 54 31 01 05 02 02 …` (published, phase 5, b6 == b7 → no pending generation, nothing for the routine to consume), `lease.record.receipt.status == absent`, and `cpu` raw words satisfying the `gen1_write_safety` invariant (`resume == delay_frame+5`, caller == overworld_loop+3, vblank flag 1) → `{row: 3, class: credits_unused}`; `derived.equal_byte = true` is informational only.
- **Row 3 equal-byte refusals:** same but `cpu={status: unavailable}` → `unknown:cpu`; same but overlay `b6 ≠ b7` with phase 5 → row 4 if `lease.record.phase == armed` and token matches, else `unknown:overlay_token`; same but `lease.record.receipt.status == present` → `unknown:receipt_without_window_progress` (P3).
- **Lease floor:** `lease={presence: present, observed_revision: 2, floor: {status: unknown}}` with an otherwise perfect row 1 → `unknown:lease.floor` (P4); `floor {verified, 5}` with observed 2 → row 11.

## 5. Boundary of proof

Derived by the classifier (checkable in unit tests from bytes alone): overlay decoding, stack-invariant arithmetic, image/party/file equalities, lease/window consistency, lease rollback arithmetic. Supplied and trusted as attestations (R0b or later cards must produce and verify them; none exists today and none is proposed here): `window.status == verified_absent`, `lease.presence`, `lease.floor`, `host.status/lineage/rollback`, `held_read_frame`, boot witnesses, image provenance. The classifier's output is diagnostic; it grants no window, replay, rebind or release, and P2b's refusal is not a field it can flip.

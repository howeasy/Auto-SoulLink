# N0 actual-CLI enrollment controller — build receipt

This is a **build-only** handoff. `.cache/n0-enrollment-successor.py` has not launched a CLI, emulator, or server; it records no physical enrollment result. Execution requires a separate sole live-lane grant and normal human New Game inputs in both emulator windows. The controller caps observation at 1800 seconds and stops only its identity-checked launched processes.

The script uses the existing selected Manager POST and bundle handlers, opens the real Gen1Runtime and TCP listener, registers the listener's actual private port before obtaining unchanged launcher bundles, and launches the actual product CLI for each player with private config and SaveRAM. It preserves downloaded zip/members, CLI logs, PID/create-time/child records, registry/runtime journal, source/input hashes, `ready-for-human.json`, periodic lightweight `progress.json`, a final JSON summary and an error/HOLD cleanup audit. It neither stages RAM, SaveRAM, savestates or CPU state nor supplies emulator inputs.

The server-persisted bounded completion oracle waits for both players' `gen1-native-reattach` released/clean entries, initial observations and bootstrap entries, initial-save receipt operations, at least one ACKed observation each, `runtime.service_current()`, and no pending server command IDs. It resolves the current native entry's event reference through the digest-checking journal API and binds the held native read and initial observation's host PID/physical owner to the exact identity-checked EmuHawk child. SQL enumerates event IDs only; journal APIs decode and verify the current snapshot and each event before sequence/ACK checks. For each player's initial save it reads the receipt-named regular file only inside that player's private SaveRAM directory, checking bytes against `gen1_initial_save_runtime.prepared(document, player)['after']['cart_hex']` and the receipt hash/length/flush/readback. The run summary retains the checked current document and event stream for independent inspection.

No gate-only Lua phase, currently held/armed state, early client-frame ordering, real-time FPS, or broad N0/release qualification can be inferred from these persisted fields. An absent field or early CLI exit yields HOLD with preserved artifacts. Human progress and actual SaveRAM materialization remain unmeasured until the granted live run.

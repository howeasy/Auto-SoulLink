- `server/board.py`: detached `project_board(status, run_id, running)` and production context/rendering. State zones: party, pending, split, boxed, unlinked, linked, fallen; Now and Log.

- `debug.js` uses `SLinkRun.fetch`, exposes `SLinkDebug.refresh`; embedded mode has no timer or SSE.
- `server/static/run-http.js`: explicit run prefix from `/runs/{id}/...`; no global fetch monkeypatch.
- `server/static/poll.js`: serial shared coordinator for application documents, including back-cache suspension/resumption. Board keeps HTMX; application pages use `/api/ui-state` for status and frozen Debug operation decisions.

### Manager/routing

- `RunManager` in `server/manager.py`; `manager_board.py` renders stopped state through frozen readers.
- `run_proxy.py`: explicit method/path allowlist, only registered loopback integer HTTP ports, raw queries/cookies/conditional/download headers, URL-attribute prefixing, real SSE relay and cancellation. Private routes are excluded.
- `X-SLink-Target-Run` rejects wrong-run requests before mutation. `X-SLink-Run-Id` verifies expected response identity. These are local routing safeguards, not gameplay admission credentials.
- Registry mutations reload/merge/write under a short lock; slow work stays outside it. Per-run locks serialize lifecycle/binding. New run IDs use UUIDs.
- `finish_mutations` protects accepted manager POST work from browser disconnect cancellation. Process stop verifies module and resolved data directory before killing a PID.
- Existing managed processes need restart with the corresponding updated server code before new private protocols work; do not silently trust old processes or kill unrelated PIDs.

### Phase 7 OBS

- `obs_arbitration.py`: versioned global config, disabled/unassigned legacy import, rule priority, per-endpoint FIFO queues, duplicate batch suppression, visible outcomes, holds on unconfirmed execution.
- `manager_obs.py`: manager APIs and private run transport; all running servers must accept the manager configuration before automatic scene execution.
- `obs_run_bridge.py`: run event forwarding, ephemeral applied configuration, revision/conflicting-revision checks, private scene execution and in-process duplicate suppression.
- Managed `OBSController` does not load/write legacy global rules. Standalone behavior is retained. Runs own actual WebSocket clients.
- Scene history, duplicate suppression, and endpoint holds are **process-local**. Phase 7 does not claim durable OBS scene recovery across manager restart. This is documented; assess any further hardening without confusing these with Gen 1 durable receipts.

### Saved source store and HTTP

`broadcast_sources.py::SourceStore` provides locked reload/merge/atomic-write CRUD:

```json
{
  "id": "server-generated 32-character UUID hex",
  "revision": 1,
  "name": "editable name",
  "run_id": "explicit registered run",
  "preset": "party",
  "players": ["a"],
  "layout": "",
  "theme": "transparent",
  "controls": {}
}
```

- Storage: `MANAGER_DIR/broadcast_sources.json`, independent of run directories/archival.
- Create requires an existing explicit run; ID/revision are assigned by server.
- Update merges fields and requires current revision; ID is immutable. Unchanged references to a subsequently deleted run remain editable.
- Delete requires current revision. New sources never reuse IDs.
- Validates preset/player/layout/theme/control combinations. `dark` normalizes to `default`. Corrupt files are preserved with 503.
- `_read` currently reads/parses the small file on each call; no store cache yet.

New manager routes:

```text
GET, POST                 /api/broadcast/sources
GET, PATCH, DELETE        /api/broadcast/sources/{source_id}
GET, HEAD                 /broadcast/sources/{source_id}
GET, HEAD                 /broadcast/sources/{source_id}/fragment
```

`manager_sources.py` obtains only the source's stored run. Live context comes from new private **POST `/_ui/broadcast-context`** on that registered run, with target/run/schema checks. Stopped pairs use `_saved_board`/frozen storage; other stopped views show placeholders. Deleted/unavailable runs never select another run.

Fragments include `X-SLink-Source-Revision`. A requested old revision or a revision change while awaiting the old upstream produces 409. Full-page races redirect back to the stable page. The source document reloads when revisions change, so layout/theme changes receive a new shell and old responses cannot restore old-run content.

### A3. Save layout (pret `include/save.h`, `src/save.c`, `include/global.h`)
The skeleton matches FRLG (`docs/gen3/research/flash_save.md`):
- 32 sectors × 0x1000, `SECTOR_DATA_SIZE` 3968, signature 0x08012025.
- 14 sections per slot: SB2 is id 0, SB1 ids 1–4, storage ids 5–13.
- Sectors 30/31 = Trainer Hill / Recorded Battle.

Sizes and offsets:
- SB2 0xF2C (FR 0xF24), with `encryptionKey` at +0xAC.
- SB1 0x3D88 (FR 0x3D68):
  - party count +0x234, party +0x238;
  - flags +0x1270, vars +0x139C;
  - pockets Items 30 / Key 30 / Balls 16 (+0x650) / TM-HM 64 / Berries 46.
- Storage 14 × 30.

The per-chunk byte ranges still need re-deriving in E1 (same macro).

## B. pokeemerald-expansion 1.17.0 (tag `expansion/1.17.0`, 2026-08-31T18:12:55Z)
- `src/rom_header_rhh.c`: `struct RHHRomHeader` is 0x18 bytes:
  - `rhh_magic[6]` "RHHEXP", then version major/minor/patch/flags;
  - `movesCount`, `numSpecies`, `abilitiesCount`, `abilities*`, `itemsCount`, `itemNameLength`, pad.
  - It sits in `.text.header_rhh`, linked right after `.text.header_gf`, which is right after `rom_header.o` (0x100 bytes). So GF is at 0x08000100 and RHH follows it; one downstream parser sees RHH at 0x204. Scan for the magic.
- `BoxPokemon` 80 / `Pokemon` 100 / substructs 12 B, with the same permutation, XOR and checksum.
  - Bitfields sit in u16 lanes: species:11 + teraType:5; heldItem:10; move1..4:11 (plus evolutionTracker bits).
  - Nickname chars 11/12 are in Substruct0.
  - `POKEMON_NAME_LENGTH` 12, `PLAYER_NAME_LENGTH` 7.
  - No `P_` config changes the box layout.
- `BattlePokemon`: `types[3]`, enum ability/item, `struct Volatiles volatiles` replaces status2/status3, `affectionHearts`.
  - `gBattleTypeFlags` is still u32.
- Save: `SECTOR_DATA_SIZE` 3968, 32 sectors, 14 per slot, 14×30 boxes.
  - SB1/SB2 fields are gated by `FREE_*` configs, so offsets are per build.
- Build: modern gcc only (`make agbcc` removed at 1.9). `make` gives `.elf/.map`; `.sym` needs `make syms`. There are `make check` / `debug` / `release` targets.
- `NUM_SPECIES` = `SPECIES_EGG` = 1573 in 1.17.0; ids are National-Dex ordered, with forms after 1572.
- `SpeciesInfo` (config-dependent fields `P_GENDER_DIFFERENCES`, `P_FOOTPRINTS`), `MoveInfo` (`include/move.h`) and `ItemInfo` (`include/item.h`) give names, types and evolutions via pointers.
- Precedent: `LJS360d/acheron-save-parser` `gba/parse.go` uses the GF header at 0x100 and RHH at 0x204. Its table pointers come from the headers; everything else comes from per-version `.map` facts.
- Public expansion forks exist (unvetted leads): good-emerald, pokeglazed, pokecrossroads, TARC2, emerald-em, infinitemadness, pokemon-emerald-loop, pokeyaeeh.

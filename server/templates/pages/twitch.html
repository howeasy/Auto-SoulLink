CONFIGURATION

⚠ twitchio 3.x setup — Twitch IRC is discontinued. You must use EventSub.
Step 1 — Register your app at dev.twitch.tv/console → Register Your Application.
  • Name: anything  • Category: Chat Bot  • OAuth Redirect URL: https://twitchtokengenerator.com/  • Client Type: Confidential
  Copy your Client ID and click New Secret to generate a Client Secret.
Step 2 — Get tokens at twitchtokengenerator.com → Custom Scope Token → paste your Client ID → enable scopes: user:read:chat user:write:chat user:bot channel:bot → Generate. Copy Access Token and Refresh Token.
Step 3 — Set env vars before starting the server (cmd.exe — no spaces, no quotes):
  set TWITCH_ACCESS_TOKEN=...   ← from twitchtokengenerator
  set TWITCH_REFRESH_TOKEN=...   ← from twitchtokengenerator
  set TWITCH_CLIENT_SECRET=...   ← from dev.twitch.tv/console → your app → New Secret
Step 4 — Fill in Channel and Client ID below, click Save Config, then Reconnect.

The run starts only from a cartridge it can vouch for byte for byte: a clean dump of Red / Blue / Yellow, or for pureRGB the pinned v2.7.6 build — or its SLink companion overlay, the same cartridge with the companion already linked in. Anything already modified is listed but greyed. Each player then downloads the cartridge the run made from the board or the Launchers menu.

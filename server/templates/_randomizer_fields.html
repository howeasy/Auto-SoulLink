{# _randomizer_fields.html — the randomizer's inputs: every option in upr_settings.OPTIONS (rendered by group from rform.options — the table is the definition of what SLink allows, so nothing is hand-listed here), the two clean ROMs (found in the SLink folder, or added through the browser's file dialog), the jar, and the preflight tags. Included inside an Alpine scope that carries the `randomizerFields()` mixin (static/randomizer.js): `rform`, `rdraft`, `roms`, `pre`, `groups()`, `scanRoms()`, `upload()`. Used by the run creator (the normal path) and by /runs/{id}/randomizer (rebuilding a pair on an existing run). #}

Types, evolutions, movesets and base stats are never randomized: the species and type clauses have to mean the same thing on both cartridges.

{# The ROMs: whatever is in the SLink folder is offered as-is (found on load, again after an upload); anything else comes in through the browser's own file dialog and lands in /roms/. The jar is found by the pipeline; it can be replaced the same way. #}

— drop your dumps there or add one above.

The randomizer starts only from a cartridge it can vouch for byte for byte: a clean dump of Red / Blue / Yellow, or for pureRGB the pinned v2.7.6 build — or its SLink companion build, the same cartridge with the native Cable Club trade and the START-menu SLINK panel linked in (Tools → Patcher makes one). Pick the companion build if you want those in-game; the randomized ROM keeps them. Anything already modified is listed but greyed.

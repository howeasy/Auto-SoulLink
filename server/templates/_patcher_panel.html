What the patch unlocks

What the patch adds to the cartridge. Both linked players need it, and a cartridge without it is refused.

  • Native trade — the real in-game trade scene on both sides (including trade-evolution), from the SLINK menu.
  • Native sound — link / KO / shiny cues play through the game's own sound engine instead of a Lua RAM-poke.
  • Bundled Battle Calc — an in-battle damage / type-effectiveness readout for the highlighted move, folded into the same patch.

Run options (Battle and Native UI groups, including Explode Mode, Rival Swap and Native Sounds) are set when you create a run in the Manager; an option the cartridge cannot honour is greyed with the reason.
